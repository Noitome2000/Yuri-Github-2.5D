# Yuri 2.5D

[中文](README.md) | [English](README.en.md) | [Español](README.es.md)

Pokemon Essentials 21.1 的 2.5D 运行时与 Maker Studio 编辑器插件，包含模型、立牌、地形和灯光工具。

> **测试版提示**：本项目目前仅为测试版本。个人开发过程中使用了部分因授权限制不便公开的插件，因此若要正常使用 3D 场景编辑器，需要自行编写 Maker Studio 适配插件，并对 [mkxp-z-ext](https://github.com/luka-sj/mkxp-z-ext) 做少量调整。

## 安装

安装前需准备 Pokemon Essentials 21.1 工程、[Maker Studio](https://github.com/Toskan4134/maker-studio)，以及支持本插件 2.5D 功能的 [mkxp-z-ext](https://github.com/luka-sj/mkxp-z-ext)。工程需事先完成配套的基础适配；仅复制本包不能完成引擎与基础工程的适配。本包不含引擎和 Maker Studio 主程序。

1. **备份并关闭工程**：先备份整个工程，再关闭游戏和 Maker Studio。升级安装时，先在 Maker Studio 中停用旧版模型与地形插件。
2. **复制插件**：将本包的 `Plugins` 文件夹复制到工程根目录，与原有 `Plugins` 文件夹合并，不要删除整个旧文件夹。
3. **放入配置**：将本包 `examples/PBS/map_3d.txt` 复制到工程的 `PBS` 文件夹。

素材存放位置见下表。不同 Maker Studio 版本的兼容性及全新工程的完整运行效果尚未逐一验证。

## 素材目录

**素材需自行准备。模型与贴图使用 `Graphics/MakerStudioPseudo3D/Models/`，编辑器导入并保存时按需创建；仅复制文件不会自动导入场景。**

| 工程内路径 | 内容 |
| --- | --- |
| `Graphics/MakerStudioPseudo3D/Models/` | 模型与贴图，含编辑器生成的 `Edited/` 子目录 |
| `Data/MakerStudioPseudo3D/library.json` | 共享资源库，部分图片内嵌其中 |
| `Data/MakerStudioPseudo3D/MapNNN.json` | 地图物件、层级、光源与效果 |
| `Data/MakerStudioTerrain/MapNNN.json` | 地形数据 |

素材、资源库及地图数据由编辑器创建，发布游戏时需保留。`Graphics/MakerStudioPseudo3D/BatchCache/` 和 `Data/MakerStudioPseudo3D/Cache/` 为自动生成的缓存，无需预建。

## 灯光

1. 在属性面板的“场景渲染”中开启 **动态场景照明**，调节“环境亮度”；适当降低亮度更容易看出灯光效果。
2. 选中地图中的模型或立牌，勾选 **作为动态光源**，选择“点光源”或“路灯（向下锥形）”，调整颜色、照明半径、灯光高度和强度。路灯还可调整照射方向、光柱张角和透明度。
3. 保存后重启游戏查看。物件光源随地图数据保存，场景照明设置与 `PBS/map_3d.txt` 同步。

**场景照明**（在“场景渲染”或 PBS 中设置，不写入事件注释）：

| 参数 | 字段名 | 默认值 | 配置说明 |
| --- | --- | --- | --- |
| 动态场景照明 | `PointLighting` | `false` | 设为 `true` 后物件与事件光源才会生效 |
| 环境亮度 | `AmbientLight` | 1 | 0.1~1.5；越小整体越暗，灯光越明显 |
| 可见灯光上限 | `MaxLights` | 8 | 1~8；同时参与照明的光源数量，超出时优先保留靠近画面中心的光源 |

**单个光源**（可在物件属性中设置，也可使用以下内部名编写事件注释；长度和高度单位为像素）：

| 参数 | 字段名 | 默认值 | 配置说明 |
| --- | --- | --- | --- |
| 作为动态光源 | `enabled`（仅物件数据） | 关闭 | 编辑器中勾选；事件中添加 `<P3D_LIGHT ...>` 即启用，无需填写此参数 |
| 光源类型 | `type` | `point` | `point` 为点光源，向四周照明；`street` 为路灯，按锥形范围向下照射 |
| 灯光颜色 | `color` | `#ffe0a0` | 六位十六进制颜色，默认暖黄色 |
| 照明半径 | `radius` | 128 | 8~640；从灯头计算，越大照得越远 |
| 灯光高度 | `height` | 48 | 0~512；相对脚下地面，物件光源还随物件高度偏移 |
| 灯光强度 | `intensity` | 0.8 | 0~3；越大越亮，0 为无照明 |
| 呼吸幅度 | `breath` | 0.08 | 0~0.5；亮度周期性起伏的幅度，0 为恒定亮度 |
| 呼吸周期（秒） | `period` | 3.5 | 0.5~30；完成一次明暗变化的时间，越大变化越慢 |
| 灯头 X 微调 | `offsetX` | 0 | -256~256；正值向右移动灯头 |
| 灯头 Y 微调 | `offsetY` | 0 | -256~256；正值向地图下方移动灯头 |
| 灯头高度微调 | `offsetZ` | 0 | -256~256；正值向上移动灯头 |

**路灯专用参数**（编辑器中选择“路灯”，或事件注释中填写 `type=street`）：

| 参数 | 字段名 | 默认值 | 配置说明 |
| --- | --- | --- | --- |
| 照射前倾角 | `tilt` | 0 | -75~75 度；0 为垂直向下，正负值向相反方向倾斜 |
| 前倾方向 | `heading` | 0 | -360~360 度；0 朝地图下方，90 朝右，180 朝上，270 朝左；垂直照射时无影响 |
| 光柱张角 | `coneAngle` | 50 | 10~140 度；越大照射锥越宽 |
| 边缘柔和度 | `softness` | 0.35 | 0.01~1；越大照射边缘越柔和 |
| 光柱透明度 | `beam` | 0.22 | 0~1；越大光柱越明显，0 隐藏光柱 |

路灯的照明半径需大于灯光高度才能照到地面；隐藏光柱不影响表面照明。

**事件灯光范例**：在事件页添加一条“注释”指令，填写下列内容。参数使用 `内部名=值`，以空格分隔；未填写的参数使用表中默认值。

```text
<P3D_LIGHT color=#ffe0a0 radius=160 height=64 intensity=1 breath=0>
```

此例为暖黄色点光源，照明半径 160 像素、高度 64 像素、强度 1，亮度恒定。需先开启“动态场景照明”；光源随事件移动，仅在包含此注释的事件页生效。
